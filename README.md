Develop a comprehensive car dealership platform, employing a Microservices architecture to ensure scalability and maintainability. The project is divided into independent services (vehicle management, orders, users) communicating via RESTful APIs.

Backend: Build services using Django & Django REST Framework (DRF), handle JWT authentication, CRUD for vehicle listings, and inventory management.

Frontend: Design a Single Page Application (SPA) interface using React, utilize React Router for navigation, and Axios to connect to the backend services.

Deployment: Package services using Docker to ensure consistency across development and production environments.
